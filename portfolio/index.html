Tucano Música

Plataforma oficial de distribuição

A Tucano Música nasceu como uma distribuidora restrita, mas cresceu e se tornou a plataforma oficial de distribuição para artistas. Um ecossistema completo, construído do zero.

  • SPA construído com HTML, CSS e JavaScript puro
  • Backend no Supabase (banco de dados + armazenamento)
  • Hospedagem na Vercel
  • App Windows via Electron (.exe) e PWA para celular
  • Arquitetura à prova de atualizações

Fluxo e dashboard

O artista faz sua candidatura enviando dados, foto do rosto, foto em frente ao estúdio e, opcionalmente, uma música. Após aprovação, tem acesso ao dashboard para criar lançamentos (Single, EP ou Álbum).

  • Capa obrigatória PNG/JPG 3000x3000 px
  • Áudio MP3/WAV entre 30s e 45min
  • Data de lançamento com 14 dias de antecedência
  • Videoclipes com validação e 28 dias mínimos
  • Status em tempo real: Revisão, Aprovado ou Rejeitado

Produção musical & engenharia de áudio

Do celular ao estúdio

Comecei a produzir no celular com BandLab, aprendendo a fazer muito com pouco. Depois migrei para o FL Studio e dei um salto gigante na qualidade. Baixei plugins profissionais de equalização, compressão, saturação e limitação — qualidade de áudio de nível industrial.

✦ Domínio da escala LUFS e comportamento de formatos de áudio.

✦ Masterização em tempo real, testada em múltiplos dispositivos e ambientes.

✦ Conheço a clássica ordem dos engenheiros: EQ, compressor, EQ.

LUFS como emoção

O LUFS não é só uma escala científica de volume — ele representa emoções. As plataformas trabalham entre -9 e -14 LUFS.

  • Dançante, alegre e bom de ouvir → -9 LUFS
  • Obscuro, profundo e introspectivo → -14 LUFS
  • Ajuste fino para cada sensação

O LUFS serve para medir volume e emoção — e eu uso isso a favor da arte.

Tecnologia & desenvolvimento

Distribuição digital e padrões

Entendo profundamente a distribuição digital e os padrões da indústria musical, incluindo metadados (DDEX), APIs, JSON e XML. Uso inteligência artificial (DeepSeek) como copiloto para escrever códigos e construir ferramentas para a gravadora, como o painel de artista.

  • SPA com HTML, CSS e JavaScript puro
  • Supabase (banco + storage)
  • Vercel (hospedagem)
  • PWA + Electron (.exe)

Ecossistema completo

A arquitetura foi pensada para que o HTML seja a fonte de verdade das contas, enquanto o localStorage salva apenas o delta de mudanças de estado — lançamentos e atualizações. Assim o sistema não quebra se o código for atualizado.

✦ Validações pesadas no navegador para capa, áudio e datas.

✦ Uploads diretos para o Supabase com status em tempo real.
